## Using Git

* You MUST NOT use `git push` or any command that would send code off the host.
* You MUST NOT perform deletions,
* You MUST NOT commit any documents in `./planning` to git
* You MAY create local commits with `git add` and `git commit`.
* If anything goes wrong with Git, you MUST NOT delete data or attempt destructive operations.
* You MUST NOT rebase changes or modify Git history
* You MUST NOT use `git filter-branch`, `git reset --hard`, or similar commands.
* If you encounter Git issues, you MUST immediately report them and exit gracefully.

## Commit Messages

* You MUST follow conventional commits for commit messages
* You MUST include many emoji to make commit messages feel fun
